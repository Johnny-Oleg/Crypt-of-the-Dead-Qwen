# Crypt-of-the-Dead-Qwen
CRYPT OF THE DEAD is complete - a 16-bit Diablo-inspired roguelike with hand-authored pixel art. Features include 10-floor roguelike descent, enemies with aggro/chase/attack AI, loot drops with weapons and armor, treasure chests, persistent blood decals, dynamic candlelight, procedural WebAudio SFX, screen shake, CRT scanlines, and full UI screens.
